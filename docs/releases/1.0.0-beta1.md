# Mercado Pago Terminal for WooCommerce 1.0.0-beta1

First beta of 1.0.0, for the WCPOS 2.0 beta. A prerelease: install the zip by hand on a test store.

The extension now runs on WCPOS Pro 2.0's shared payments base and requires WCPOS Pro 2.0.0 or later. Without a compatible Pro it shows an admin notice and registers nothing.

## Changed

- A Mercado Pago Orders-API adapter drives a Point Smart terminal through Pro's ledger: an order per ledger row, polling, cancellation, signed webhooks on Pro's route, and refunds.
- Pro manages reader selection and lifecycle, logging redaction and the support bundle.
- Live attempts from the previous extension are adopted into Pro's ledger on upgrade; the old cron is cleared and old metadata is kept.
- Historical refunds keep the `ORD…` transaction reference and resolve `PAY…` only for partial-refund payloads.
- Carries the 0.1.1 behaviour: amounts are sent in the store's price decimals (a store priced without decimals sends whole units), an order whose Mercado Pago currency differs is not completed, and Mercado Pago's error details appear in API error messages.

The full list is in `CHANGELOG.md` under 1.0.0.
