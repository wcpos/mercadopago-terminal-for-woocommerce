# Mercado Pago Terminal for WooCommerce 0.1.0

**Untested on a live account:** this integration has not yet been run against a Mercado Pago account or a physical Point Smart terminal. It is built from Mercado Pago's developer documentation and covered by unit tests against the documented payloads. Treat it as a beta and test with Mercado Pago's sandbox (test credentials and the virtual terminal) before taking real payments.

## Added

- Cashiers send the order total to a Point Smart terminal from the order-pay page and follow the payment until Mercado Pago confirms it. The order then completes and the POS shows its receipt.
- Payments complete exactly once, whether the poll, the webhook or the 5-minute background sweep sees the result first. A retried start never creates a second charge.
- Terminals in STANDALONE mode can be switched to PDV from the settings page (restart the terminal afterwards).
- Full and partial refunds from the WooCommerce order screen.
- Debug logging and a Download support bundle button, so a problem can be diagnosed from the first report.

## Upgrade

First release. Paste the access token from your Mercado Pago application, register the webhook URL shown in the settings with the "Order (Mercado Pago)" event, and paste the secret signature. Switch your terminal to PDV mode. Then enable the gateway under WooCommerce POS → Settings → Checkout. If anything goes wrong, use **Download support bundle** on the settings page and attach the file to your support request.
